# singlebarrellabs-site

One-page site for Single Barrel Labs LLC, served at singlebarrellabs.com.

Static HTML and CSS. No build step, no dependencies, no JavaScript.

## Files

| File | Purpose |
|---|---|
| `index.html` | The page |
| `styles.css` | All styling |

## Local preview

```sh
open index.html
```

Or serve it:

```sh
python3 -m http.server 8000
```

## Deploying

Push to `main`.
